# Project charter (one page)

Copy this, fill it in, and paste it into a [Register a project](https://github.com/joinoasa/techtree/issues/new?template=register-project.yml) issue, or keep it as the README of your project repo. Short and honest is better than long. Delete these notes.

## Project name

## Goal
What will exist when this is done? Two sentences at most.

## Why it matters
Which tech tree nodes does it build or use, and what does it unlock? List node IDs.

## Lead and team
- **Lead:** GitHub username (an OASA member). Responsible for keeping the project moving and updated.
- **Team:** GitHub usernames and what each person does.

## Type and access
- **Personal** (yours, with OASA's support) or **Community** (open for others to join).
- Who can see it and who can join: everyone, members only, or invite only.

## Milestones
1. **First milestone** (what you will show or test, and roughly when):
2. Next:
3. Done means: it meets the [release standard](https://joinoasa.org/docs/projects/#release-standard).

## Safety and legal
Anything that flies, drives, swims or moves: who is responsible when it is tested, where it will be tested, and what could go wrong. Say "not applicable" for software and documents only.

## Resources
Hardware, money, tools and skills you have, and what you are missing.

## Licence
Open licence for code (for example Apache-2.0) and for documents and designs (for example CC BY-SA 4.0).

## Updates
Where progress is posted (usually the node issues) and how often. Projects with no update for 30 days may be marked inactive.
